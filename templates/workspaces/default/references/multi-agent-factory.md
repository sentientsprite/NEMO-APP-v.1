# Multi-agent factory pattern

## User-facing stages
Understand → Plan → Approve → Execute → Verify → Report

## Why separate agents
- Wrong assumptions caught at brief approval, not after 10 files changed
- Backend and frontend builders can run in clean contexts
- Validator never fixes — only reports truth

## Product templates
- Research this business
- Analyze these documents
- Turn notes into tasks

Each template defines stages, approval gates, and expected outputs.
